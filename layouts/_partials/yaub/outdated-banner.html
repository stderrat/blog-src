{{- /* yaub/outdated-banner.html Shows a notice on articles that are likely outdated. Rules (first match wins): 1. front matter "evergreen: true" -> no banner 2. front matter "eol_note: " -> banner with that text (AsciiDoc/Markdown allowed) optional "superseded_by: /path/" -> link to the successor article 3. age of "reviewed" (or date) > site.Params.outdatedAfterMonths (default 24) -> generic banner "reviewed" is used instead of Lastmod on purpose: a typo fix must not make a 2020 article look current. The banner is calculated at build time, which is fine for a site that is rebuilt on every push. */ -}} {{- if and .IsPage (not .Params.evergreen) -}} {{- $months := site.Params.outdatedAfterMonths | default 24 -}} {{- $ref := .Date -}} {{- with .Params.reviewed -}}{{- $ref = time.AsTime . -}}{{- end -}} {{- $cutoff := now.AddDate 0 (mul -1 $months) 0 -}} {{- $successor := "" -}} {{- with .Params.superseded_by -}}{{- with site.GetPage . -}}{{- $successor = . -}}{{- end -}}{{- end -}} {{- if .Params.eol_note }}
Outdated: {{ .Params.eol_note | .RenderString }} {{- with $successor }} See {{ .LinkTitle }} instead.{{ end }}
{{- else if $ref.Before $cutoff }}
This article was written {{ time.Format "January 2006" $ref }}. Product versions, commands and screenshots may have changed since then. Please verify against the current documentation. {{- with $successor }} A newer article is available: {{ .LinkTitle }}.{{ end }}
{{- end -}} {{- end -}}
